# アイデア置き場（検討メモ）

思いついたアイデアと、その評価をここに残す。採用が決まったものだけ別途 Issue 化または PR で実装する。
進捗管理は PR とマージで行い、ここは「検討」と「優先度」の記録専用とする。

最終更新: 2026-11-02

## 優先度まとめ

| # | アイデア | 難易度 | 優先度 |
|---|---------|--------|--------|
| 1 | フォント初期値ランダム | 極低 | 高（即採用候補） |
| 2 | ランの道場破りイベント | 中低 | 高（好感度とセットで本命） |
| 3 | キャラ別好感度 | 中 | 中（土台系） |
| 4 | パワーアップアイテム | 中 | 中（基盤工事） |
| 5 | 表情差分 | 中 | 低（段階導入） |
| 6 | 状態異常 | 中〜高 | 低（慎重枠・検証必須） |

推奨の実装順: 1 → 2+3（道場破りと好感度は一体で設計） → 4 → 5（試作から） → 6（2種から試験導入）

---

## 1. フォント初期値ランダム

- 概要: 錬成フローに入るたび、初期フォントを FONTS からランダムに選ぶ。色のランダム化（PR #11）と同じ仕組み・同じ場所。
- 難易度: 極低（数行）。フロー内の戻る／次へでは選んだフォントを保持する（色と同じ挙動）。
- 効果: 流派まで毎回変わるため、「適当に作ると全部同じ子になる」問題が消える。
- リスク: ほぼなし。

## 2. ランの道場破りイベント

- 概要: 不定期にランが「嵐」を連れて勝負を挑んでくる。受けると手元の子で対戦（相手は総合力×0.95 目安）。
  - 断る → ランの好感度低下（しょんぼり台詞・表情差分の見せ場）
  - 受ける → 好感度アップ
  - 勝つ → さらに好感度アップ＋手元の子のステータス+α（ランダム1種+3 など、育成が壊れない範囲）
- 難易度: 中低。Phase 2 の野生モンスター襲来の基盤（専用画面→選択→迎撃バトル→結果画面）がそのまま流用できる。
- 発生: 通常ランダムイベントとは別枠の抽選（試合日でない日、1日あたり約5%目安）。襲来と同日には発生させない。
- 前提: #3 の好感度（最低限ラン分）があると完成度が上がる。

## 3. キャラ別好感度

- 概要: キャラごとに好感度を持ち、担当アクションやイベント選択で少しずつ上がる。段階（顔なじみ／仲良し／大好き）で各キャラ固有のメリットが解放される。
- セーブ: `GameState.affection: Record<SpeakerId, number>` を追加（旧セーブは防御的に読む）。
- 上昇機会の例: 冬眠・復活（チルミ）、配合（ツムギ）、ごはん（モグミ）、殿堂入り・記録閲覧（シオリ）、大会出場（コトハ）、ストーリー既読（話者）、道場破りの結果（ラン）、研究所の利用（モジカ）。
- メリットの例（小さく刻む）:
  - チルミ: 冬眠明けの調子ボーナス
  - モグミ: 餌のなつき効果アップ
  - ツムギ: 配合時のステータス下限保証アップ
  - コトハ: 大会賞金+10%
  - シオリ: 売却額+10%
  - モジカ: 育成ヒントの質向上（台詞バリエーション増）
  - ラン: 道場破りの報酬アップ／大会後の特別台詞
- 必須の相方: 好感度と特典が見える「キャラ一覧画面」を 1画面1機能で新設する。
- 注意: 上昇を作業化させない（日常のプレイで自然に上がる量に留める）。数値は直接見せず段階表示を基本とするかは要検討。

## 4. パワーアップアイテム

- 概要: 消費アイテムの導入。今は所持品の概念自体がないため、在庫・入手・使用の3点セットと「アイテム画面」（1画面1機能）が新規に必要。
- アイテム案（効果は既存パラメータに寄せる）:
  - 特訓ドリンク: 次回の特訓・自主練の伸び+50%
  - 活力の実: 調子を全快
  - 絆のお守り: なつき+15
- 入手: 購入（G）＋野生モンスター襲来・道場破りの報酬にすると世界の循環ができる。
- 難易度: 中。バランス面は「既存効果の増幅」に限定すれば安全。

## 5. 表情差分

- 概要: キャラの表情バリエーション（笑顔／怒り／悲しみ／驚きなど）で感情表現を増やす。
- 難易度: 中。主コストは画像生成と「同じ顔に見えるか」の一貫性リスク。7人分を一気に作らない。
- 段階導入案:
  1. まずモジカとラン（使い所が明確な2人）の顔アイコン差分だけ試作し、画風の一貫性を確認する。
  2. 問題なければ担当者全員に展開。立ち絵差分は最後。
- 表示先の候補: メッセージ窓の顔アイコン（話者の感情で切替）、道場破りのしょんぼり顔、ストーリー閲覧画面。

## 6. 状態異常

- 概要: バトルに状態異常を入れる。ただしポケモンの用語・仕様の直写しは避け、文字の世界観に寄せた独自命名とする。
- 命名案:
  - 毒 → 「滲み」（文字が滲んで毎ターン少しずつ削れる）
  - 麻痺 → 「固まり」（文字が固まって時々動けない）
  - 混乱 → 「乱れ」（文字が乱れて自分を傷つけることがある）
  - やけど → 「焦げ」（焦げて攻撃が弱り、少しずつ削れる）
  - 眠り → 「夢うつつ」
  - 氷 → 「凍り字」
- ゲーム性を損なわないための条件:
  - 持続は最大3ターン、付与は属性有利ヒット時の低確率のみ。
  - オート観戦が間延びしないこと（行動不能の連続に上限）。
  - 大会バランス（動的スケーリング前提の勝率）が崩れないか、シミュレーションで検証してから入れる。
- 難易度: 中〜高。バトルエンジン（simulateBattle）の中核改修になる唯一の案。
- 導入方針: 「滲み」「固まり」の2種から試験導入し、勝率への影響を見て増やす。
